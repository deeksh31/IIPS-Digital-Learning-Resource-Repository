# IIPS Digital Learning Resource Repository System

## 📚 Project Overview

The IIPS Digital Learning Resource Repository System is a web-based application developed to provide a centralized platform for storing, managing, searching and accessing digital learning resources.

The system allows students and faculty members to access useful educational resources such as notes, study materials, PDFs and other learning content.

An administrator can manage users, resources, categories and resource approvals.

---

## 🎯 Objectives

- Provide a centralized digital learning resource repository.
- Allow students to search and access learning materials.
- Allow faculty members to upload educational resources.
- Provide an approval system for uploaded resources.
- Allow administrators to manage users and resources.
- Make learning resources easy to find and access.

---

## 🚀 Features

### Student
- Student registration and login
- View learning resources
- Search resources
- Browse resources by category
- View resource details
- Download learning resources
- Manage profile

### Faculty
- Faculty login
- Upload learning resources
- Add resource title and description
- Select resource category
- Manage uploaded resources

### Administrator
- Admin login
- Admin dashboard
- View total users
- View total resources
- Approve pending resources
- Reject resources
- Delete resources
- Manage categories
